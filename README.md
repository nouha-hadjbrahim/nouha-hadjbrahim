## 💡 About me

I started with software development — Java, Spring Boot, Angular — before discovering that what
I really enjoy is the layer underneath. For my final-year project, my team and I built a private
OpenStack cloud from scratch rather than renting one: compute, storage, identity and networking,
then an Ansible-automated Kubernetes cluster on top, with Prometheus and Grafana to actually see
what was happening. With no infrastructure team behind us, every failure was ours to diagnose —
and that is what made me want to do this for a living.
